TRADUGUARÁ — Instruções
1. Hospede todos os arquivos juntos em HTTPS (ex.: GitHub Pages, Netlify).
2. Abra o endereço no navegador e escolha Instalar aplicativo, quando disponível.
3. Após o primeiro carregamento, o site pode funcionar offline.
4. Para testar localmente, use um servidor HTTP (ex.: python -m http.server 8000); não abra diretamente por file://.
5. As palavras personalizadas e o histórico são salvos no localStorage do navegador; exporte o JSON para backup.
6. O vocabulário é introdutório e precisa de validação com falantes de guarani. O tradutor é lexical e não analisa flexões, sintaxe ou contexto.
